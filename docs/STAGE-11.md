# Stage 11 — AI Platform Foundation

The Core Plugin now provides provider-neutral AI contracts, a safety guard, a credit repository boundary and an orchestrator. Automotive AI is guidance and triage, not a definitive diagnosis. High-risk automotive warnings are escalated to professional help. Prompt injection patterns are blocked, output must be non-empty, provider failure is surfaced as graceful degradation and credits are refunded on provider failure.

Schema version `10` defines conversations, messages, credit accounts, credit transactions, usage logs, knowledge documents, knowledge chunks and versioned prompts. No commercial AI provider or credential is activated. Provider, model, cost, retention and AI-write policy remain configuration/Founder decisions; no runtime or production AI claim is made.

Local verification: 48 tests and 88 assertions across all available contracts. AI provider calls, latency, token accounting, RAG retrieval, moderation and runtime persistence are `Not Runtime Verified`.
